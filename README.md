# EX No.5.1.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
## Step 1

Open Autodesk Fusion 360 and select Part Design. Create a new design and choose the XY plane to start the sketch. Draw the base outline using the required sketching tools according to the given engineering drawing. Apply the specified dimensions and constraints to complete the base profile.

<img width="830" height="535" alt="image" src="https://github.com/user-attachments/assets/8674d533-c216-4719-a564-e0f724c99f49" />

## Step 2

Finish the sketch and use the Extrude command to create the base flange with a thickness of 15 mm. Select the top surface and draw the required mounting holes of Ø12 mm at the specified positions. Use the Extrude Cut command to remove the material and create the holes as shown in the drawing.

<img width="242" height="350" alt="image" src="https://github.com/user-attachments/assets/655725e6-60c3-461e-b4c9-65bab2ebbc60" />


## Step 3

Select the top surface of the base plate and start a new sketch. Draw four concentric circles with diameters of Ø46 mm, Ø40 mm, Ø20 mm and Ø10 mm at the centre of the base plate. Use the Circle tool and apply the required dimensions to create the central boss profiles and opening.

<img width="426" height="431" alt="image" src="https://github.com/user-attachments/assets/7525ba88-41c2-45ca-ad7f-f1be739982a3" />

## Step 4

Select the required circular profile and use the Extrude command to raise the central cylindrical portion to a height of 40 mm. Use the Extrude Cut command to remove the inner material and create the stepped portion. Ensure that the central opening and stepped structure match the given drawing.

<img width="242" height="350" alt="image" src="https://github.com/user-attachments/assets/8c143c87-fc90-48f1-8d01-ae33e95110c7" />

## Step 5
Create the supporting ribs between the central cylindrical boss and the base plate according to the given engineering drawing. Use the appropriate sketching and modelling tools to form the supporting structure. Maintain the required overall height of 85 mm and ensure that all the parts are properly connected.

## Step 6

Select the required edges and apply fillets of R2, R3, R10 and R12 using the Fillet command to obtain a smooth finish. Check all the dimensions and complete the 3D model. Save the design and select Drawing → From Design to generate the required orthographic views, including front, top and side views.

<img width="202" height="552" alt="image" src="https://github.com/user-attachments/assets/a6447d89-c6a6-4c06-b365-ae0d8671f1db" />

Check all dimensions, complete the 3D model and save the design.
